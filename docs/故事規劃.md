# 故事規劃

## 一句話

男孩打開自己曾經的音樂庫，一首首旋律帶他回到過去的感情；他每一關都跟著音樂去找女孩，最後找到的，是自己。

## 核心設定

- **主角**：男孩。
- **音樂庫**：每一首旋律對應一段感情時期，一首旋律就是一關。
- **每一關的路程**：男孩聽著音樂去找女孩。路上的機關象徵這段關係裡的種種困難，但只要跟著音樂，男孩總能找到她在哪裡，走到她身邊。
- **結局**：最後一關的終點，男孩找到的不是女孩，而是自己，明白自己活著的意義是自己。

## 關卡與時期

| 關卡 | 時期 | 旋律感覺 |
|---|---|---|
| 1 | 開始喜歡上女孩 | 甜甜的、心動 |
| 2 | 追求 | 苦澀 |
| 3 | 告白成功 | 雀躍 |
| 4 | 熱戀 | 12/8 拍的浪漫旋律 |
| 5 | 日常 | 輕快 |
| 6 | 感情逐漸變得不一樣 | 微妙、不安 |
| 7 | 因現實考量而改變的關係 | 沉重 |
| 8 | 分手 | 痛苦 |
| 9 | 分手之後 | 感傷 |
| 10 | 找到自己 | 釋懷 |

## 玩法和劇情怎麼接

- **跟著節奏才找得到路**，就是「男孩在音樂的幫助下找到女孩」。
- 現有機關可以對應情緒，例如：
  - 加速：現實壓力，生活越來越快；
  - 休止：關係裡的沉默與距離；
  - 盲拍：分手後看不清方向，只能靠聲音前進。
- 終點的女孩可以隨劇情變化：前期在終點等他，後期越來越遠、甚至消失，最後一關終點站著的是男孩自己。
