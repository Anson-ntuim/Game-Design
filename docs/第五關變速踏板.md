# 第五關：強制變速線

插在輕重力第四關與原挑戰關之間；挑戰關順延為第六關，八段節奏變奏順延為第七關。

穿過垂直變速線立即切換 BPM。藍色減速、橘色加速、綠色回到 120；線覆蓋整個畫面高度，走、跳或衝刺經過都會生效，停在線上不會重複觸發。每個入口提供安全地面、長椅與起跳旗。

| 路段 | BPM | 操作重點 |
| --- | --- | --- |
| 慢拍階梯 | 90 | 慢速學會落地接跳，平台逐段升高 |
| 快拍光門 | 150 | 長跳、音符接跳、空中穿柱 |
| 慢拍短句 | 96 | 兩次短跳接長跳，快段後換氣 |
| 極速環橋 | 168 | 正拍穿環、半拍穿第二環、再衝刺 |
| 原拍階梯 | 120 | 黃藍平台交接，重新整理節奏 |
| 混速接力 | 120 → 156 → 90 | 同一段中途穿線，連招與變速交替 |
| 尾奏 | 120 | 穿綠線恢復原速，走向終點 |

音樂播放倍率、Engine.time_scale 與節拍機關共用 Conductor 的倍率，角色、特效與世界同步變速。切換時先保留原歌曲位置再改倍率，節拍不跳動；跳躍與機關的距離維持同一套設計數值。變速關不受原本「走到區塊後下一小節換 BPM」邏輯覆蓋。

長椅保存當下的基礎速度，死亡後恢復該速度。重開或回選關會由 Conductor.start 恢復原速。HUD 常駐顯示 BPM 與速度倍率。

舊存檔沒有 level_order_version 時，索引 4 起的成績順延一格；下次存檔寫入版本 2，之後不會再次搬移。新第五關不會繼承原挑戰關成績。

重建：`python3 tools/tempo_course.py --write`。

驗證：`Godot --headless --path . --fixed-fps 120 --script res://tools/check_climbing_levels.gd`。包含第四／五／七關實際角色回放，以及全關光柱延伸、穿線、空中強制切速、高速穿越、重複觸發、音樂／世界倍率、角色移動、節拍連續性、長椅復原與存檔搬移測試。測試會還原原始成績檔。

驗證結果：500 項檢查通過，Godot 實際遊戲亦確認 90 BPM／0.75 倍與 150 BPM／1.25 倍同步切換。

光柱的碰撞延伸到關卡底下 128 px，光效延伸到相機下緣之外，所有關卡都不再顯示懸空柱底。
